## 📌 About This Repository

**Open-Cv** is a structured learning repository for Computer Vision and Image Processing using **Python** and **OpenCV**. It contains eight progressive learning phases, practical exercises, image and video assets, XML classifier files, and a dedicated project folder.

The repository is designed to build practical, hands-on skills in:

- Reading, displaying, and processing images
- Applying image-processing and transformation techniques
- Working with webcam and video input
- Detecting faces and objects using OpenCV
- Building real-time computer-vision applications
- Organizing reusable Python scripts for learning and experimentation

This repository reflects my journey toward becoming a **Machine Learning and AI Engineer**, with a particular focus on Computer Vision, Deep Learning, and Artificial Intelligence.
